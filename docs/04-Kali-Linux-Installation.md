# 04 - Kali Linux Installation

## Objective
To download and import Kali Linux into Oracle VirtualBox as the attacking machine for the cybersecurity testing lab.

## Software Requirements
- Oracle VirtualBox
- Kali Linux Virtual Machine image

## Official Download
Kali Linux:
https://www.kali.org/get-kali/

## Installation Procedure

### Step 1: Download Kali Linux
1. Visit the official Kali Linux website.
2. Navigate to the Virtual Machines section.
3. Download the VirtualBox-compatible Kali Linux image.

### Step 2: Extract the Downloaded File
1. Locate the downloaded archive.
2. Extract it using 7-Zip if required.
3. Locate the VirtualBox machine configuration file.

### Step 3: Import Kali Linux
1. Open Oracle VirtualBox.
2. Select the option to add or import the Kali Linux virtual machine, depending on the downloaded format.
3. Locate the extracted virtual machine files.
4. Complete the import process.

### Step 4: Start Kali Linux
1. Select the Kali Linux virtual machine.
2. Start the VM.
3. Verify that the Kali Linux desktop loads successfully.

## Verification
- Kali Linux VM is available in VirtualBox.
- Kali Linux starts successfully.
