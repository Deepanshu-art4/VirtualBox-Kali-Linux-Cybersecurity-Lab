# 08 - Virtual Machine Snapshot

## Objective
To create a snapshot of the Kali Linux virtual machine to preserve its current state.

## Procedure

1. Open Oracle VirtualBox.
2. Select the Kali Linux virtual machine.
3. Open the Snapshots section.
4. Select Take Snapshot.
5. Enter a snapshot name.
6. Add a description.
7. Confirm snapshot creation.

## Suggested Snapshot Name

Kali-Linux-Initial-Lab-Setup

## Purpose of Snapshot

- Preserve the configured VM state.
- Provide a recovery point.
- Support future cybersecurity lab activities.
- Help restore the VM to its saved state when needed.

## Verification

Check that the snapshot appears in the VirtualBox Snapshots section.
