# 01 - Lab Overview

## Project Name
VirtualBox Kali Linux Cybersecurity Lab

## Objective
To establish a cybersecurity testing environment using Oracle VirtualBox and Kali Linux.

## Lab Architecture

- Host Machine: Windows 11
- Virtualization Platform: Oracle VirtualBox
- Attacking Machine: Kali Linux
- Network Type: NAT Network
- Network Subnet: 10.0.0.0/24
- Kali IP Address: 10.0.0.2/24

## Requirements

- Laptop or desktop computer
- Oracle VirtualBox
- 7-Zip
- Kali Linux Virtual Machine
- Internet connection

## Main Activities

1. VirtualBox installation.
2. NAT Network creation.
3. Kali Linux VM import.
4. IP configuration.
5. Shared folder configuration.
6. Internet connectivity verification.
7. VM snapshot creation.

## Expected Result

A configured Kali Linux virtual machine with network connectivity, host-to-guest file sharing, and a saved VM snapshot.

Lab setup documentation in progress.
